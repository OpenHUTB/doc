Python 程序调试

VScode

  1. 按Ctrl+Shift+P，输入Python:Select Interpreter并选择；
  2. 选择或创建所需的Python解释器；
  3. 单击行号左侧设置断点；
  4. 点击右上角三角箭头，选择Python Debugger: Debug Python File；

shell

wget -O
-O : (output) 以指定的文件名保存

cut -d " " -f 1
-d: 指定字段的分隔符，默认的字段分隔符为“TAB”；

-f: 显示指定字段的内容；
